# SMA-EMA-Trend-Strategy-Backtester
SMA/EMA Trend Strategy Backtester  A Python backtester that compares 20/50-day SMA and EMA crossover strategies on Nifty 50 daily data (2007 onward) against a buy-and-hold benchmark.  Methodology Long/flat rule: hold the index when the fast average is above the slow one, otherwise stay in cash.
